# assets/

Drop your project images here. The site expects:

| File                        | Used in              |
|-----------------------------|----------------------|
| `twitch-clip-editor.png`    | Projects card 01     |
| `video-storyboarder.png`    | Projects card 02     |

**Tips:**
- Screenshots, demo GIFs, or short screen recordings all work.
- Aim for roughly 16:9 or wider — the card crops to a fixed 160px height.
- PNG or WebP preferred. GIFs work too (they'll autoplay).
- If a file is missing the card shows a placeholder — no errors.

To add a new project card, edit `src/data/projects.ts`.
