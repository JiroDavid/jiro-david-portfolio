# wallpapers/

Drop your wallpaper images here. One per workspace.

| File            | Workspace | Theme            |
|-----------------|-----------|------------------|
| `home.jpg`      | HOME      | dark / JRPG      |
| `projects.jpg`  | PROJECTS  | sakura / pink    |
| `skills.jpg`    | SKILLS    | purple / anime   |
| `contact.jpg`   | CONTACT   | forest / green   |

**Tips:**
- JPG, PNG or WebP all work.
- Landscape orientation preferred (16:9 or wider).
- The image fills the full desktop via `background-size: cover`.
- If a file is missing the solid fallback colour shows instead — no errors.
- Aim to match the accent palette per workspace so the window colours feel native.

To change a wallpaper path, edit `src/data/workspaces.ts` → `wallpaper` key.
